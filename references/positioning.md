## 1. 签字位置如何判定

脚本按文档顺序扫描每个段落（含表格内段落），满足以下任一条件即判为候选签字行，且该段落当前不含图片（防止重复签署）：

- 中文文本包含字符「签」（覆盖：签字、签名、签章、签署、会签、续签、承诺人签字等）或「落款」
- 英文文本包含：`signature`、`sign here`、`signed`、`signatory`

`scan` 子命令会列出每个候选位置的序号、所在位置和段落原文，供确认后再插入。

## 2. 支持的位置类型

- 正文段落
- 表格内段落（自动递归，输出形如「正文 › 表格(第2行,第1列)」）
- 合并单元格会自动去重，不会重复计数
- 文末兜底：无任何候选位置时，在末尾空一行、右对齐放置签名（见第 7 节）

## 3. 签名尺寸如何控制

- 默认宽度按姓名长度自适应：约每字 26pt，并限制在 58pt～150pt。
- 高度始终按签名图片的真实宽高比等比计算，只固定宽度，不会拉伸变形。
- 签名图片以 4 倍超采样渲染并裁剪到文字边界，插入后清晰、无多余留白。
- 用 `--width` 手动指定宽度（pt）：偏大则调小，偏小则调大。
- 默认内联追加到「签字：」标签之后；如需放到标签下一行，加 `--new-line`。

## 4. 日期填写

加 `--fill-date` 可对「日期：」后为空白的段落追加当天日期（格式：YYYY年M月D日）。

局限：带下划线的「____年__月__日」排版不做强行替换，以免破坏原有版式；这类位置需要人工填写或在确认后单独处理。

## 5. 字体选择与自定义

内置两款字体，均位于 `assets/fonts/`，用 `--font` 加编号或别名选择：

| 编号 | 名称 | 别名 | 文件 | 风格 |
|------|------|------|------|------|
| 1 | 龙藏体 | longcang、龙藏 | LongCang-Regular.ttf | 笔画较粗、连笔潇洒（SIL OFL 1.1） |
| 2 | 平方长安 | changan、长安、平方 | PingFangChangAnTi-2.ttf | 纤细清秀、字形端正 |

运行 `fonts` 子命令可查看清单。也可用 `--font 路径.ttf` 指定外部字体，要求 FreeType 可正常渲染并覆盖目标姓名用字。

> 注意：辰宇落雁（ChenYuluoyan）因 FreeType 渲染报错且简体缺字约 24%，不可用于本工具。

## 6. 批量签署（多个文档）

`batch` 有两种模式。

文件夹整批（内容相同）：

```bash
python3 scripts/sign_docx.py batch --input-dir "待签文件夹" --name "王佳蓓" --font 2
```

清单模式（逐文件不同内容）。CSV 为 UTF-8 编码、两列（文件名,签署内容），带表头：

```
文件名,签署内容
合同A.docx,同意 张灿
确认单B.docx,李宏伟
```

```bash
python3 scripts/sign_docx.py batch --manifest "清单.csv" --font 2
```

- 字体只解析一次并应用到整批；批量时同样先在对话中确认字体。
- 签署内容可含空格与任意文字；清单按 `utf-8-sig` 读取，兼容 Excel 导出的 BOM；重复文件后者覆盖。
- 清单文件路径支持绝对路径或相对清单目录，`--input-dir` 可作为额外相对基准。
- 默认每份文档内所有候选位置都签；`--first-only` 改为每份文档只签第一个位置。
- 输出默认写入“批量签署结果”目录，文件名按“原文件名_签署人已签署.docx”重命名（自动去掉末尾“模板”、去除内容中的空格），不覆盖原件；`--output-dir` 可指定。
- 自动跳过 `~$` 锁文件；文件夹模式用 `--recursive` 递归，并跳过输出目录。
- 单文件失败被隔离并记录，结束后输出成功/失败汇总，退出码在有失败时为 1。

## 7. 故障排查

| 现象 | 原因与处理 |
|------|-----------|
| 扫描不到位置 | 自动走文末兜底：与最后一行文字空一行、右对齐签名；如需固定位置可补「签字：」标签后重试 |
| 提示位置序号超范围 | 先 `scan` 确认有效序号（从 0 开始） |
| 同一处被重复签 | 已含图片的段落会被自动跳过；如需重签请用原始未签文档重新生成 |
| 签名偏大/偏小 | 用 `--width` 调整，或加 `--new-line` 改为单独成行 |
| 批量提示无 .docx | 确认文件夹路径正确；`~$` 锁文件会被跳过，加 `--recursive` 可含子文件夹 |
| 批量中个别文件失败 | 失败已隔离，不影响其他文件；按汇总信息修正该文档后单独重签 |
| 输入是 .doc 旧格式 | python-docx 不支持 .doc；先用 Word/WPS「另存为 .docx」再处理 |
| 生僻字显示异常 | 换用覆盖该字的字体，通过 `--font` 指定 |

> 说明：本工具生成的是视觉层面的手写字体签名，并非带 CA 证书、可加密验签的数字电子签名。
